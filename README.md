# FunToast: Polytechnic Life Survival Game 🍞✨

**FunToast** is a funny, fast-paced, interactive browser-based game designed for polytechnic students. Built as a single self-contained HTML5 file with zero dependencies, it runs completely offline on laptops, desktops, tablets, and smartphones.

---

## 🎮 Game Concept & Storyline

In **FunToast: Poly Life Survival**, you play as a poly student trying to graduate without getting "toast" (burnt out). Balance your **Stress Meter**, **Energy/GPA**, and **Time** across multiple relatable campus scenarios:

- **Chapter 1: The Group Project Crisis** — Manage a freeloading teammate and battle the legendary 23:59:00 campus Wi-Fi upload glitch.
- **Chapter 2: The Monday 8:00 AM Lecture & Canteen Rush** — Escape the front-row pop quiz and race against the clock in the Canteen Speed Snack Minigame.
- **Chapter 3: The Final Exam Project Defence** — Defend your bugged demo in front of strict examiners with humor, diplomacy, or emergency toast!

---

## ✨ Features

- **100% Self-Contained & Offline:** All HTML5, CSS3, JavaScript, SVG graphics, and Web Audio synthesizer sound effects are embedded inside [`FunToast.html`](FunToast.html). No internet or external CDNs required.
- **Synthesized Audio Engine:** Native Web Audio API generates sound effects for clicks, success jingles, crunch sounds, and alert buzzers without external audio files.
- **Interactive Gameplay & Minigames:** Multiple-choice branching decisions with real-time feedback plus interactive reflex clicker minigames.
- **Resource Management (HUD):** Dynamic Countdown Timer, Stress Meter, and Energy Bar with game-over burnout mechanics.
- **Local Leaderboard:** Saves and ranks top scores locally via `localStorage` with automatic in-memory fallback.
- **Responsive & Touch-Friendly:** Optimised for Mac, PC, iPad, iPhone, and Android browsers.

## 🚀 How to Play

### On macOS (MacBook / iMac)
1. Double-click [`FunToast.html`](FunToast.html) in Finder, or
2. Open via Terminal:
   ```bash
   open -a "Google Chrome" FunToast.html
   # or
   open -a Safari FunToast.html
   ```

### On Windows / Linux
- Double-click `FunToast.html` or drag and drop it into Chrome, Edge, or Firefox.

### On Mobile / Tablet
- AirDrop, email, or transfer `FunToast.html` to your device and tap to open in Safari / Chrome.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and UI layout.
- **CSS3:** Responsive styling, flexbox/grid layout, smooth animations, floating toast particles.
- **Vanilla JavaScript:** Game loop, procedural stage rendering, score calculations, timer, and state machine.
- **Web Audio API:** Real-time waveform audio synthesis.
- **Inline SVG:** Scalable, responsive character avatars and mascot art.
